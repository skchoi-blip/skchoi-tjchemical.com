## 📋 현장 안전 점검표 (`hermes_checklist.html`)

태주 HERMES Sales Lite의 데이터 백업 검증 및 테스트 데이터 정리를 위한 현장 점검용 A4 인쇄 최적화 서식입니다.

### 1. 파일 열기 방법
- **로컬에서 열기:** 저장소를 Clone하거나 `hermes_checklist.html` 파일을 다운로드한 뒤, 크롬(Chrome) 또는 엣지(Edge) 브라우저로 더블클릭하여 엽니다.
- **온라인 바로 열기:** 상단 안내 바의 인쇄 기능을 통해 로컬 웹브라우저에서 바로 렌더링됩니다.

### 2. A4 1페이지 인쇄 및 PDF 저장 방법
1. 브라우저 화면 상단의 파란색 **[🖨️ PDF 저장 / 인쇄]** 버튼을 클릭하거나, 키보드의 `Ctrl + P` (Mac: `Cmd + P`)를 누릅니다.
2. 인쇄 설정 창에서 다음 옵션을 지정합니다:
   - **대상(프린터):** `PDF로 저장` (또는 실제 A4 프린터)
   - **용지 크기:** `A4`
   - **페이지 방향:** `세로 (Portrait)`
   - **배율:** `기본(100%)` 또는 `맞춤`
   - **머리글 및 바닥글:** `체크 해제` (문서 자체의 전용 레이아웃 적용)
   - **배경 그래픽:** `체크(선택)` (표 음영 표시)
3. **[저장]** 또는 **[인쇄]**를 누르면 표나 서명란이 잘리지 않고 **A4 1장에 완벽히 안착**된 점검표가 출력됩니다.
